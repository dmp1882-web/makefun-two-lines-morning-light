# Two Lines of Morning Light

make.fun bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5` (program/v1).

A two-line micro poem about light and morning, turning on one image of light arriving like a letter.

## Entry

```
Light slips under the door like a letter —
by the time I read it, the whole room is awake.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
